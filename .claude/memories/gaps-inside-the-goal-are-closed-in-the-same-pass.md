# Gaps inside the goal are closed in the same pass

When work on a goal turns up something else that falls under the same goal, fix it as part of that work. Reporting it as a known gap or a follow-up is only for things that need a decision the user alone can make.

**Why:** a goal stated as a rule covers every case of it, so reporting a case as left open hands back work that was already asked for.

**How to apply:**

- Before reporting, ask of each item left unfixed whether the stated goal already covers it. If it does, do it.
- A larger change, or tests that have to change, is no reason to defer.
- Same spirit as [Red CI gets fixed, not filed](red-ci-gets-fixed-not-filed.md).
